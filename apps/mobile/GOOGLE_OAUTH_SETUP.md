# Google Photos OAuth setup (Android debug)

Create an **Android OAuth 2.0 client** in the Google Cloud project that has the **Google Photos Picker API** enabled. Register these exact values:

- OAuth redirect URI used by Photeo: `com.photeo.app:/oauthredirect`
- Android package name: `com.photeo.app`
- Debug-keystore SHA-1: `5E:8F:16:06:2E:A3:CD:2C:4A:0D:54:78:76:BA:A6:F3:8C:AB:F6:25`

The SHA-1 above is from `apps/mobile/android/app/debug.keystore`, generated by Expo prebuild and used by the debug Gradle signing config. A release build will need a separate OAuth Android client registered with the release keystore SHA-1.

Set the generated Android client ID before starting or building the app:

```sh
export EXPO_PUBLIC_GOOGLE_ANDROID_CLIENT_ID="YOUR_ANDROID_CLIENT_ID.apps.googleusercontent.com"
```

The app uses Authorization Code + PKCE (S256) and requests only:

`https://www.googleapis.com/auth/photospicker.mediaitems.readonly`

After OAuth, Photeo creates a Photos Picker session, opens its `pickerUri`, polls until `mediaItemsSet` is true, lists the selected media, and uses each short-lived `baseUrl` to read only the items the user explicitly selected.
